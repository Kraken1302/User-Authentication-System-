# 🎮 Kaun Banega Crorepati (KBC) - Console Game

A fun, console-based quiz game inspired by the popular TV show *Kaun Banega Crorepati*. This project tests the user with multiple-choice questions, tracks score, and simulates the game experience through terminal interactions.

## 📌 Features

- Multiple-choice quiz format with increasing prize money.
- Tracks total winnings for the user.
- Instant feedback on correct and incorrect answers.
- Easy to expand with more questions.

## 🧠 Technologies Used

- **C++**: Core game logic and user interaction.
- **Standard I/O**: For terminal-based gameplay.
- **Windows.h**: For adding sleep delays and clearing the screen (platform-specific).
